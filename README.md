# Витклинер — готовый статический сайт

Текущий публичный адрес: <https://yaroslavkiri4ykknifhit-max.github.io/cleaner/>

Сайт работает без CMS, базы данных и сборки на сервере. Для публикации достаточно загрузить всё содержимое репозитория в корень сайта. HTML, CSS, JavaScript и изображения локальные; внешних шрифтов и CDN нет.

## Что входит

- адаптивная главная с понятным маршрутом до звонка или оценки по фото;
- каталог услуг без стоковых карточек;
- галерея из восьми реальных пар «до / после»;
- отдельные страницы химчистки мебели, диванов, матрасов, кресел и стульев, кожаной мебели, ковров, ковролина, салона авто, мойки окон и окон после ремонта;
- страница расчёта стоимости, политика конфиденциальности и страница 404;
- рабочая подготовка сообщения для Viber и прямые телефонные ссылки;
- семантическая разметка, уникальные title/description/H1, canonical, Open Graph, robots.txt и sitemap.xml.

## Домен и сборка

Исходником страниц служит `scripts/build.py`. Сейчас canonical и sitemap настроены на GitHub Pages. Для собственного домена пересоберите сайт одной командой:

```bash
SITE_URL=https://ваш-домен.by python scripts/build.py
```

Затем загрузите содержимое репозитория в корень хостинга. На сервере Python не требуется — он нужен только для пересборки. Для локальной проверки:

```bash
python scripts/build.py
python -m http.server 8000
```

## После публикации

1. Добавьте окончательный адрес в Google Search Console и Яндекс Вебмастер.
2. Отправьте `https://ваш-домен.by/sitemap.xml` в оба кабинета.
3. Запросите переобход главной и ключевых страниц услуг.
4. Добавьте компанию в Google Maps и Яндекс Бизнес с одинаковым названием, телефоном и зоной обслуживания.
5. Подключайте Метрику и Analytics только с реальными идентификаторами.

Техническая оптимизация помогает поисковым системам понять и индексировать сайт, но не гарантирует конкретные позиции или срок выхода в топ: на это также влияют домен, конкуренция, отзывы, ссылки и поведение пользователей.
