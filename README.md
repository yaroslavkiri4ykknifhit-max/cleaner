1. Добавить URL-prefix `https://yaroslavkiri4ykknifhit-max.github.io/cleaner/` в Google Search Console и адрес сайта в Яндекс Вебмастер. Для подтверждения воспользоваться предложенным HTML-файлом или meta-тегом; добавлять только реальные коды из кабинета.
2. Передать в оба кабинета `https://yaroslavkiri4ykknifhit-max.github.io/cleaner/sitemap.xml`.
3. Проверить URL главной и ключевых услуг в кабинетах, запросить обход после подтверждения.
4. Заполнить реальные профили компании в картах, добавлять новые работы и актуальную информацию. Органическая видимость зависит от спроса, конкуренции, репутации и качества контента. Настройка не гарантирует индексацию, позиции или заявки.
5. При подключении домена позднее поменять `BASE` в `scripts/build.py`, пересобрать страницы, обновить Open Graph и карту сайта. Не подключать домен заранее.

## Редактирование

Страницы генерирует `scripts/build.py`. Для локальной пересборки нужен Python 3 и Pillow (`python -m pip install pillow`). Затем:

```bash
python scripts/build.py
python -m http.server 8000
```

GitHub Pages использует уже сгенерированные HTML; Python на хостинге не требуется. Контент, телефон, адрес сайта и SEO находятся в генераторе. Оформление — `assets/site.css`, интерактивность — `assets/site.js`.

Все исходные скриншоты сохранены в `images/`. В `assets/work/` находятся извлечённые фотографии без чёрных полей и интерфейса телефона, с сохранением настоящего результата. Пары составлены по исходному порядку. Фотографии сделаны с разных ракурсов, поэтому используется сравнение рядом, а не наложение двух несовпадающих объектов.

Фон гостиной (`assets/hero.webp`), процесс чистки (`assets/process.webp`) и окно (`assets/windows.webp`) — сгенерированные интерьерные иллюстрации. Они не являются фото клиентских работ. Галерея содержит только исходные реальные фотографии. Краткое описание заданий для генерации: светлая гостиная с тканевым диваном и спокойным пространством под текст; крупный план экстракторной чистки обивки; мойка окна профессиональным склизом. Метод: встроенная генерация изображений.

## Аналитика

Подготовка сообщения и нажатие ссылки не равны полученной заявке. При подключении аналитики отслеживать эти действия отдельно.
