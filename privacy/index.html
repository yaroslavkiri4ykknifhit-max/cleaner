Конфиденциальность

Эта страница объясняет, как работает сайт Витклинер и подготовка заявки.

Подготовка сообщения

Поля формы обрабатываются в вашем браузере. Сайт не отправляет введённый текст на сервер компании, не сохраняет его в локальном хранилище и не создаёт заявку автоматически. Копирование в буфер обмена происходит только после нажатия кнопки «Скопировать текст».

Связь по телефону и в Viber

Ссылки открывают приложение звонков или сторонний сервис Viber через viber.click. Данные и фотографии передаются только тогда, когда вы сами отправляете сообщение. У сторонних сервисов действуют собственные правила обработки данных. Не включайте в заявку сведения, которые не нужны для обсуждения услуги.

Хостинг и технические данные

Сайт опубликован на GitHub Pages. Хостинг может обрабатывать технические сведения о запросах по своим правилам. На сайте не установлены рекламные пиксели, счётчики аналитики и собственные cookies.
